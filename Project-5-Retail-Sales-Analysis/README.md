# Retail Sales Analysis Dashboard

## Objective

The objective of this project is to analyze retail sales data and generate meaningful business insights using Exploratory Data Analysis (EDA). The project focuses on cleaning the dataset, performing filtering and sorting, calculating sales and profit statistics, analyzing region-wise and category-wise performance, and creating visualizations to understand sales trends.

---

## Dataset

**Dataset Name:** Superstore Sales Dataset

**Source:** Kaggle

**Dataset Link:**  
https://www.kaggle.com/datasets/vivek468/superstore-dataset-final

---

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## Project Workflow

The following steps were carried out during the project:

1. Imported the required Python libraries.
2. Loaded the Superstore Sales dataset using Pandas.
3. Explored the dataset using:
   - `head()`
   - `shape`
   - `info()`
   - `describe()`
4. Cleaned the dataset by handling missing values and duplicate records.
5. Performed filtering and sorting operations.
6. Calculated sales and profit statistics.
7. Analyzed region-wise sales and profit performance.
8. Analyzed category-wise sales and profit performance.
9. Created visualizations to understand business trends.
10. Summarized the observations through Exploratory Data Analysis (EDA).

---

## Statistical Analysis

The following statistical measures were calculated for the numerical features:

- Mean
- Median
- Mode
- Variance
- Standard Deviation
- Total Sales
- Total Profit

These measures helped in understanding the overall sales and profit performance of the business.

---

## Visualizations

The following plots were created during the analysis:

- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Correlation Heatmap
- Box Plot

---

## Key Findings

- The dataset was successfully cleaned before analysis.
- Sales and profit statistics provided an overview of business performance.
- Region-wise analysis identified high-performing and low-performing regions.
- Category-wise analysis showed the contribution of different product categories to overall sales and profit.
- Visualizations made it easier to identify sales trends and business patterns.

---

## Conclusion

This project provided practical experience in analyzing retail sales data using Exploratory Data Analysis (EDA). It covered data cleaning, filtering, sorting, statistical analysis, regional and category-wise performance analysis, and visualization techniques. The insights obtained from the analysis can support better business decision-making.
