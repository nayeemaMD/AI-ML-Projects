# Titanic Survival Prediction

## Objective
Predict whether a passenger survived the Titanic disaster using machine learning algorithms.

## Dataset
Titanic Dataset

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Models Used
- Logistic Regression
- Decision Tree

## Project Workflow
- Loaded and explored the dataset
- Handled missing values and duplicate records
- Detected outliers using the IQR method
- Performed exploratory data analysis
- Encoded categorical variables
- Applied StandardScaler
- Trained and compared machine learning models

## Conclusion
This project applies data preprocessing, visualization, and machine learning techniques to predict passenger survival accurately.
