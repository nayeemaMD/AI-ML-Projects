# Wine Quality Exploratory Data Analysis

## Objective

The objective of this project is to explore the Wine Quality dataset using Exploratory Data Analysis (EDA). The project focuses on understanding the dataset, performing descriptive statistics, analyzing correlations, identifying highly correlated features, detecting outliers, filtering and sorting the data, and visualizing important patterns to understand the factors affecting wine quality.

---

## Dataset

**Dataset Name:** Wine Quality Dataset

**Source:** Kaggle

**Dataset Link:**  
https://www.kaggle.com/datasets/yasserh/wine-quality-dataset

---

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## Project Workflow

The following steps were carried out during the project:

1. Imported the required Python libraries.
2. Loaded the Wine Quality dataset using Pandas.
3. Explored the dataset using:
   - `head()`
   - `shape`
   - `info()`
   - `describe()`
4. Performed descriptive statistical analysis.
5. Calculated the correlation matrix.
6. Identified highly correlated features.
7. Detected outliers using the IQR method.
8. Filtered and sorted the dataset.
9. Created visualizations to understand the data.
10. Summarized the observations through Exploratory Data Analysis (EDA).

---

## Statistical Analysis

The following statistical measures were calculated for the numerical features:

- Mean
- Median
- Mode
- Variance
- Standard Deviation
- Correlation Matrix

These measures helped in understanding the distribution, variation, and relationships among different wine characteristics.

---

## Visualizations

The following plots were created during the analysis:

- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Correlation Heatmap
- Box Plot

---

## Key Findings

- The dataset was explored and summarized successfully.
- Descriptive statistics provided a clear understanding of each feature.
- Highly correlated features were identified using the correlation matrix.
- Outliers were detected using the IQR method.
- Filtering and sorting helped analyze different groups of wine samples.
- Data visualizations made it easier to understand the relationship between wine characteristics and quality.

---

## Conclusion

This project provided practical experience in performing Exploratory Data Analysis (EDA) on the Wine Quality dataset. It covered descriptive statistics, correlation analysis, outlier detection, filtering, sorting, and visualization techniques. The analysis helped identify the important factors that influence wine quality.
