# Student Performance Analysis

## Objective

The objective of this project is to analyze student exam performance using Exploratory Data Analysis (EDA). The project focuses on understanding the dataset, performing statistical analysis, identifying outliers, analyzing correlations, and visualizing the data to gain meaningful insights into student performance.

---

## Dataset

**Dataset Name:** Students Performance Dataset

**Source:** Kaggle

**Dataset Link:**  
https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

---

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## Project Workflow

The following steps were carried out during the project:

1. Imported the required Python libraries.
2. Loaded the dataset using Pandas.
3. Explored the dataset using:
   - `head()`
   - `shape`
   - `info()`
   - `describe()`
4. Checked for missing values and handled them.
5. Identified and removed duplicate records.
6. Calculated statistical measures:
   - Mean
   - Median
   - Mode
   - Variance
   - Standard Deviation
7. Detected outliers using the IQR method.
8. Performed correlation analysis on numerical features.
9. Created visualizations to understand the dataset.
10. Summarized the observations through Exploratory Data Analysis (EDA).

---

## Statistical Analysis

The following statistical measures were calculated for the numerical features:

- Mean
- Median
- Mode
- Variance
- Standard Deviation

These measures helped in understanding the distribution and variation of students' scores.

---

## Visualizations

The following plots were created during the analysis:

- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Correlation Heatmap
- Box Plot

---

## Key Findings

- The dataset was successfully cleaned by handling missing values and duplicate records.
- Statistical analysis provided a clear understanding of student score distributions.
- Outliers were identified using the IQR method.
- Correlation analysis showed a strong relationship between reading and writing scores.
- Data visualizations made it easier to identify patterns and compare student performance.

---

## Conclusion

This project provided practical experience in performing Exploratory Data Analysis (EDA) using Python. It covered data cleaning, statistical analysis, outlier detection, correlation analysis, and visualization techniques. The insights obtained from the analysis help in understanding student performance more effectively.
