# Student Performance Analysis

## 🎯 Objective

To analyze student exam performance and identify the factors affecting students' final grades using Exploratory Data Analysis (EDA).

---

## 📂 Dataset

**Student Performance Dataset**

**Dataset Link:**  
https://www.kaggle.com/datasets/devansodariya/student-performance-data

---

## 🛠️ Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📋 Tasks Performed

- Loaded the dataset
- Performed Exploratory Data Analysis (EDA)
- Checked missing values and duplicates
- Calculated statistical summary
- Detected outliers
- Performed correlation analysis
- Created visualizations (Histogram, Boxplot, Scatter Plot, Heatmap)

---

## 📊 Results

The analysis revealed important patterns in student performance and showed how factors such as parental education, lunch type, and test preparation influence exam scores.
