# House Price Prediction

## Objective
Develop regression models to predict house prices using housing features.

## Dataset
Housing Prices Dataset

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Models Used
- Simple Linear Regression
- Multiple Linear Regression

## Project Workflow
- Loaded and explored the dataset
- Calculated statistical measures
- Identified skewness and outliers
- Performed correlation analysis
- Selected important features
- Trained regression models
- Compared RMSE and R² Score
- Predicted prices for unseen houses
- Saved the trained model

## Conclusion
This project demonstrates the use of linear regression techniques to estimate house prices and evaluate model performance using regression metrics.
