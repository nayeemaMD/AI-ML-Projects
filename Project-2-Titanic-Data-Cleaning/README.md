# Titanic Data Cleaning & Passenger Analysis

## Objective

The objective of this project is to clean the Titanic dataset and analyze passenger survival trends using Exploratory Data Analysis (EDA). The project focuses on handling missing values, removing duplicate records, identifying outliers, filtering data, grouping passengers, calculating survival statistics, and visualizing important patterns.

---

## Dataset

**Dataset Name:** Titanic Dataset

**Source:** Kaggle

**Dataset Link:**  
https://www.kaggle.com/datasets/yasserh/titanic-dataset

---

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## Project Workflow

The following steps were carried out during the project:

1. Imported the required Python libraries.
2. Loaded the Titanic dataset using Pandas.
3. Explored the dataset using:
   - `head()`
   - `shape`
   - `info()`
   - `describe()`
4. Checked for missing values and handled them.
5. Identified and removed duplicate records.
6. Detected and treated outliers using the IQR method.
7. Filtered passengers based on:
   - Age
   - Gender
   - Passenger Class
8. Grouped the data using `groupby()`.
9. Calculated passenger survival statistics.
10. Created visualizations to understand passenger survival trends.
11. Summarized the observations through Exploratory Data Analysis (EDA).

---

## Statistical Analysis

The following statistical analysis was performed:

- Passenger Count
- Survival Count

- Gender-wise Survival Analysis

These analyses helped in understanding passenger characteristics and survival patterns.

## Key Findings

- Missing values were successfully handled before analysis.
- Duplicate records were removed from the dataset.
- Outliers were identified using the IQR method.
- Female passengers showed a higher survival rate than male passengers.
- First-class passengers had a better survival rate compared to other passenger classes.
- Visualizations clearly showed the relationship between passenger characteristics and survival.
