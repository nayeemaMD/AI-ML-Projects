# Customer Purchase Prediction

## Objective
Build machine learning models to predict whether a customer will purchase a product based on customer information.

## Dataset
Social Network Ads Dataset

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree

## Project Workflow
- Loaded and explored the dataset
- Handled missing values and duplicates
- Encoded categorical features
- Performed data visualization and correlation analysis
- Applied StandardScaler
- Trained and evaluated machine learning models
- Compared Accuracy, Precision, Recall, and F1-Score
- Saved the best model using Joblib

## Conclusion
This project demonstrates the complete machine learning workflow for predicting customer purchase behavior using classification algorithms.
