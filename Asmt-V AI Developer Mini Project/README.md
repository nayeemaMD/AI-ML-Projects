# AI Developer Mini Project - Diabetes Prediction

## Objective

The objective of this project is to build an end-to-end Machine Learning application that predicts whether a patient has diabetes based on medical information. The project covers the complete Machine Learning workflow, from data loading and preprocessing to model training, evaluation, and prediction.

---

## Dataset

**Dataset:** Pima Indians Diabetes Dataset

**Source:** Kaggle

The dataset contains medical information of female patients, including:

- Pregnancies
- Glucose
- Blood Pressure
- Skin Thickness
- Insulin
- BMI
- Diabetes Pedigree Function
- Age
- Outcome (Diabetic / Not Diabetic)

## Steps Performed

- Imported the required Python libraries.
- Loaded the dataset using Pandas.
- Cleaned the dataset by removing duplicate records.
- Created reusable Python functions for:
  - Loading data
  - Cleaning data
  - Splitting data
  - Training models
  - Making predictions
  - Saving the trained model
- Split the dataset into training and testing sets.
- Applied StandardScaler for feature scaling.
- Trained multiple Machine Learning models:
  - Logistic Regression
  - K-Nearest Neighbors (KNN)
  - Decision Tree
- Compared model performance using:
  - Accuracy
  - Precision
  - Recall
  - F1-Score
- Displayed the Confusion Matrix.
- Saved the best-performing model using Joblib.
- Built a prediction function to classify new patient data as Diabetic or Not Diabetic.
