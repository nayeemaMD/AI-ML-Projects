# Diamond Price Analysis

## Objective

The objective of this project is to analyze the factors influencing diamond prices using Exploratory Data Analysis (EDA). The project focuses on cleaning the dataset, handling missing values and duplicates, detecting outliers, analyzing categorical and numerical features, calculating statistical measures, and visualizing relationships between different variables.

---

## Dataset

**Dataset Name:** Diamonds Dataset

**Source:** Kaggle

**Dataset Link:**  
https://www.kaggle.com/datasets/shivam2503/diamonds

---

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## Project Workflow

The following steps were carried out during the project:

1. Imported the required Python libraries.
2. Loaded the Diamonds dataset using Pandas.
3. Explored the dataset using:
   - `head()`
   - `shape`
   - `info()`
   - `describe()`
4. Checked for missing values and handled them.
5. Identified and removed duplicate records.
6. Detected and treated outliers using the IQR method.
7. Analyzed categorical and numerical features.
8. Calculated statistical measures.
9. Performed correlation analysis.
10. Created visualizations to understand the relationships between different features.
11. Summarized the observations through Exploratory Data Analysis (EDA).

---

## Statistical Analysis

The following statistical measures were calculated for the numerical features:

- Mean
- Median
- Mode
- Variance
- Standard Deviation
- Correlation Matrix

These measures helped in understanding the distribution and variation of the diamond characteristics and prices.

---

## Visualizations

The following plots were created during the analysis:

- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Correlation Heatmap
- Box Plot

---

## Key Findings

- The dataset was successfully cleaned by handling missing values and duplicate records.
- Outliers were identified and analyzed using the IQR method.
- Correlation analysis showed that carat weight has a strong positive relationship with diamond price.
- Numerical and categorical feature analysis helped understand the characteristics of diamonds.
- Data visualizations clearly explained the relationship between diamond features and their prices.

---

## Conclusion

This project provided practical experience in performing Exploratory Data Analysis (EDA) on a real-world diamonds dataset. It covered data cleaning, statistical analysis, outlier detection, feature analysis, correlation analysis, and visualization. The analysis helped identify the major factors that influence diamond prices.
